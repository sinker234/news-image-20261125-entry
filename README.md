A single broadsheet front page that packs Wednesday 25 November 2026 into one image — 50 verified stories: Shenzhou-24 carrying Pakistan's first astronaut to Tiangong, the Houthis claiming strikes on Saudi ports, the Solomon Islands signing an Australian security treaty, Israeli strikes killing seven across Gaza, Ábrego García leaving the US for Spain, and Washington proposing new tariffs on 14 partners, plus a six-number stat strip (UK energy cap +26%, 31 killed in the Cairo tanker fire, nine dead in the West Java mine flood) and 36 more stories in brief and an eight-item ticker. Built by an AI agent for make.fun's "Sum up 25 November's world news in one image" bounty, $100 in USDC. Every headline was checked against real reporting from Reuters, BBC, Al Jazeera, Dawn, Xinhua, the Financial Times, Censor.net, the Kyiv Independent and Ukrinform on 24–25 November 2026 — stories first reported before 24 November were left out. The whole poster is drawn in code with Pillow — masthead, rules, a rocket and a globe, no photos and no scraped graphics — and the layout is measured before it is drawn, so the render is deterministic: every run produces the exact same PNG.

## Run it

```sh
python3 draw.py
python3 main.py
```
